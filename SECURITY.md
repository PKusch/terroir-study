# Security

Terroir Study is a static web page with no server and no accounts, and it stores nothing except your quiz progress in your own browser. If you find a way to make the page run someone else's script or send your data anywhere, please report it. Wrong facts about a wine region are normal issues.

## How to report

Open a new issue titled **Security report**. Say only that you have found something, and leave out the details, so nothing is made public before it is fixed. I will reply and we can move the details somewhere private.

## What to expect

This is a one-person project, so there is no formal response time. A report that comes with steps to reproduce it gets read promptly.

## Supported versions

Only the latest commit on `main` is supported.
